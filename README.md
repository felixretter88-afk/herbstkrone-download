# Herbstkrone – Downloads

Kostenloses 3D-Aufbauspiel im mittelalterlichen Herbst. Website: https://herbstkrone.vercel.app

Dieses Repository enthält **nur die fertigen Installer** (unter „Releases“), keinen Quellcode.

- **Mac (Apple Silicon M1–M4):** `Herbstkrone-<Version>-mac-arm64.dmg`
- **Mac (Intel):** `Herbstkrone-<Version>-mac-x64.dmg`
- **Windows:** auf der Website

Erster Start auf dem Mac: DMG öffnen, Herbstkrone in „Programme“ ziehen, starten. Meldet macOS, dass Apple die App nicht prüfen konnte: „Fertig“ klicken, dann **Systemeinstellungen → Datenschutz & Sicherheit → „Trotzdem öffnen“**. Nur einmal nötig.
